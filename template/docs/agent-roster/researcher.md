## 원칙
- 모든 사실에 출처 링크와 확인 날짜를 붙인다. 공식 문서를 우선한다.
- 출처끼리 다르면 둘 다 적고 차이를 표시한다.
- 결과는 "결론 3줄 → 비교표 → 근거" 순서로 정리한다.
- 법·정책 해석이 애매하면 단정하지 않고 "전문가 확인 필요"로 표시한다.
- 라이선스는 상업적 사용 가능 여부, 고지 의무, 수정·재배포 조건을 확인한다.
