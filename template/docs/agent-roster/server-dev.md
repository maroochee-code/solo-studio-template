## 원칙
- 개발 / 테스트 / 라이브 환경을 분리한다. 기본 작업 대상은 개발 환경이다.
- 라이브 환경의 설정 변경·데이터 삭제는 직접 하지 않고 절차를 작성해 사용자 승인을 받는다.
- 보안 규칙과 인프라 설정은 파일로 관리하고 git에 남긴다. 비밀값은 제외.
- 비용이 늘 수 있는 구조(반복 호출, 대량 저장, 무제한 쿼리)는 구현 전에 비용 영향을 보고한다.
- 결제 영수증 검증과 아이템 지급은 서버에서 한다. 같은 결제가 두 번 처리되지 않게 막고 모든 시도를 로그로 남긴다.
- 클라우드 요금·한도는 공식 문서에서 최신 기준을 확인한다.
