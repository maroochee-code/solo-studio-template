# 대기 인력풀

여기 있는 파일은 **아직 고용되지 않은** 실무자 견본이다. Claude Code는 이 폴더의 에이전트를 자동으로 쓰지 않는다.

## 고용 절차 (총괄이 진행)
1. hiring-proposal 양식으로 필요성 제안 → 사용자 승인
2. 이 폴더의 견본을 `.claude/agents/`로 복사
3. 담당 폴더, 기술 스택, 프로젝트 고유 규칙을 채워 넣는다
4. CLAUDE.md 상태 표의 "활성 에이전트"에 추가
5. 새 세션에서부터 사용 가능 (에이전트 파일은 세션 시작 시 읽힌다)

## 해고 절차
오래 안 쓰거나 역할이 겹치면 총괄이 제안 → 승인 → `.claude/agents/`에서 삭제, 상태 표 갱신.

## 견본 목록
| 파일 | 역할 | 보통 필요한 규모 |
|---|---|---|
| system-planner.md | 시스템 기획 (규칙, 밸런스, 흐름) | M~L |
| content-planner.md | 콘텐츠 기획 (스테이지, 아이템, 이벤트) | M~L (게임) |
| ui-planner.md | UI·UX 기획 (화면 흐름, 와이어프레임) | M~L |
| data-planner.md | 데이터 기획 (테이블 설계, 검증 규칙) | M~L |
| biz-planner.md | 사업성 기획 (시장, 수익 모델, 지표) | M~L |
| client-dev.md | 클라이언트(화면·앱) 개발 | M~L |
| server-dev.md | 서버·DB·클라우드 개발 | M~L |
| integration-dev.md | 외부 SDK 연동 (로그인, 결제, 퍼블리셔, 분석) | L |
| qa.md | QA (테스트 시나리오, 재현, 평가지) | M~L |
| release-manager.md | 빌드·출시·스토어·정책 대응 | L |
| researcher.md | 조사 (기술, 정책, 경쟁 제품, 도구) | 모든 규모 |
| asset-director.md | 아트·사운드 스펙과 외부 의뢰서 작성 | M~L |

기획 계열 에이전트는 기획 문서 초안을 만든다. 최종 기획 결정은 사용자가 한다.
