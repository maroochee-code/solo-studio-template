# 출시 체크리스트

정책·규격은 자주 바뀐다. 출시 때마다 **공식 문서 최신판 기준으로** 확인하고 근거 링크를 `docs/release/runbook.md`에 남긴다.

## 빌드
- [ ] 동결 단계로 전환했는가
- [ ] 버전 이름·버전 코드·빌드 번호 자동 증가 확인
- [ ] 라이브 환경 설정으로 빌드 (테스트 서버 주소, 디버그 메뉴, 테스트 결제 제거)
- [ ] 빌드 서명·인증서 (만료일 확인)
- [ ] 비밀값이 빌드나 저장소에 포함되지 않았는가
- [ ] 플랫폼 기술 요건 (예: 안드로이드 타깃 API 레벨, iOS 최소 버전·SDK 요건)

## 로그인·계정
- [ ] 로그인 수단 조합이 스토어 규정에 맞는가 (소셜 로그인 + 애플 로그인 요건 등)
- [ ] 앱 안에서 계정 삭제 가능
- [ ] 소셜 로그인 콘솔 설정 (앱 ID, 해시·번들 ID, 리디렉션, 앱 검수 상태)

## 결제
- [ ] 상품 ID가 콘솔과 데이터 테이블에서 일치
- [ ] 국가별 가격 확인
- [ ] 예외 시나리오 전체 테스트 통과 (중단, 대기, 환불, 복원, 중복, 기기 변경)
- [ ] 서버 영수증 검증과 결제 로그
- [ ] 결제 방식이 스토어·국내 규정에 맞는가 (외부 결제 포함 시 특히)

## 개인정보·법규
- [ ] 개인정보 처리방침 URL
- [ ] 애플 개인정보 라벨 / 구글 데이터 보안 섹션 = `data-collection.md`와 일치
- [ ] 추적 권한 요청(해당 시)
- [ ] 등급 설문, 국내 등급분류(해당 시)
- [ ] 확률형 아이템 정보 공개(해당 시)
- [ ] 이용약관
- [ ] 오픈소스·폰트 라이선스 고지 화면 (자동 생성 스크립트)

## 스토어 자료
- [ ] 아이콘: 플랫폼별 최신 규격 (적응형·단색·다크·틴트 등 변형 포함), 원본에서 스크립트로 생성
- [ ] 스크린샷·대표 이미지 규격
- [ ] 앱 이름, 짧은 설명, 긴 설명, 키워드 (`store/`에 저장)
- [ ] 문의 이메일, 웹사이트
- [ ] 심사용 테스트 계정·설명 (로그인이 필요하면)

## 운영 준비
- [ ] 롤백 방법 확인 (이전 빌드, 서버 설정 되돌리기)
- [ ] 핫픽스 절차 (`docs/rules/stage-5-live.md`)
- [ ] 크래시·로그 수집 동작 확인
- [ ] 클라우드 예산 알림
- [ ] 공지·고객 문의 창구

## 제출
- [ ] runbook 순서대로 진행
- [ ] **제출·출시 버튼은 사용자가 직접**
