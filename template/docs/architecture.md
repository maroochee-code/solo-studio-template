# 아키텍처 (본설계 단계에서 작성)

## 수정 이력
| 버전 | 날짜 | 변경 내용 |
|---|---|---|

## 1. 전체 흐름
(입력 → 처리 → 출력, Mermaid 도표 권장)

## 2. 폴더와 책임
```
src/
  core/          골격 (승인 없이 수정 금지)
  integrations/  외부 SDK·서비스 창구 (로그인, 결제, 분석, 클라우드 ...)
  ...
data/            기획 데이터 테이블
tests/
docs/
```

## 3. 골격 규칙
(예: 새 화면은 BaseWindow 상속 / 모듈 간 통신은 이벤트로만 / 데이터 변경은 Command로만)

## 4. 확장 지점
(Base 클래스별로 부모가 하는 일과 자식이 덮어쓰는 함수)

## 5. integrations 인터페이스
| 인터페이스 | 역할 | 현재 연결된 SDK |
|---|---|---|
| LoginService | 로그인·로그아웃·계정 삭제 | |
| PaymentService | 상품 조회·구매·복원 | |
| AnalyticsService | 이벤트 기록 | |

## 6. 환경
| 환경 | 용도 | 주소·프로젝트 ID |
|---|---|---|
| dev | 개발 | |
| test | 테스트·베타 | |
| live | 라이브 | |

## 7. 성능 예산
(프레임, 로딩 시간, 용량, 월 비용 상한)

## 8. 결정 기록
구조 관련 결정은 docs/decisions.md에 남기고 여기서 링크한다.
